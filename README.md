# Ednie-Kerr2025
Code and data for the manuscript "Microclimate-scale thermal extremes limit butterfly patch use in a protected ecosystem" by Ednie&amp;Kerr

The coding workflow for the unmanned aerial vehicle (UAV)-acquired data processing is provided. Prior to running this code, thermal infrared (TIR), visual (red, green, blue), digital terrain (dtm), and digital surface (dsm) maps were generated using the Pix4D mapper software. This software creates orthomosaics from individual pictures captured in both the TIR and visual wavelengths from a sensor mounted on a UAV. This code also requires air temperature data collected at regular intervals throughout the period of interest using temperature loggers placed *in situ* (in our case iButton loggers).

The coding workflow is numbered in the order in which they were (and should be) run. 

The following is a description of additional data that was needed in each script:
1. iButton air temperature data in csv form and a csv detailing the date, start time, end time, section, and order of each UAV survey to isolate the temperatures captured during each UAV survey. The section indicates which area was sampled at a given date. The order indicates the order of the survey (i.e., was it the first or third time that section was surveyed on that date).
2. A csv file detailing the exact location of each iButton temperature logger. This includes information on longitude, latitude, iButton ID, and section of deployment
3. Emissivity rasters for each UAV survey. These were generated by performing a surface classification of all visual maps in ArcGIS Pro, assigning an emissivity value based on the literature for every surface type in the raster attribute table, and creating new rasters based on those emissivity values.
4. DTM and DSM maps generated by Pix4D in their own folders
